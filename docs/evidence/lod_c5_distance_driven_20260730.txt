  The coarse world renders with long STRIPE-SHAPED GAPS (screenshot
  screenshots/screenshot_20260730_142242_593.png). Full detail at the same pose is solid and
  correct (screenshot_20260730_142341_103.png). Uniform level 2 via /api/debug/lod_level
  reproduces the striping, so it is NOT mixed-level cracking between chunks at different levels.
  Uniform level 3 rendered SOLID earlier, so it is level-dependent.

  NARROWED: a new invariant test (HeightfieldHasNoHolesFromAboveAtEveryLevel) builds a
  terrain-like heightfield chunk and asserts every (x,z) cell column with solid content emits an
  upward face, at levels 0-3. It PASSES. So per-chunk top-face coverage is CORRECT and the defect
  is INTER-CHUNK, not a hole in a single chunk's coarse mesh.

  NOT YET DIAGNOSED. Candidate causes still open, in the order worth testing:
    1. Per-chunk GPU span capacity: setFacesFromLod may write more instances than the chunk's
       arena span holds (level 1 RAISES total faces 250,845 -> 410,004), and a silent truncation
       would drop geometry. Check span capacity vs faces.size() on swap.
    2. Boundary faces: the coarse mesher emits a full skirt at every chunk border (atClamped
       reads out-of-volume as empty). Coincident skirts between neighbours could z-fight or,
       with back-face culling, leave the interior visible through them.
    3. numInstances vs the dirRanges sentinel interplay in setFacesFromLod.

  DO NOT ship distance-driven LOD until this is diagnosed. The toggle defaults OFF.
