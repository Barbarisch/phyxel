Method (F2.8's, unchanged):
- Scene: VoxFoundGate game.json (WorldGenerator Perlin s7, flora, static chunks x 254..257, y 0..1, z 2..5).
  A = today's store as GameDefinitionLoader loads it ({"hide_world":false,"show_preview":false}).
  B = the same chunks at 1/8 m by /api/debug/voxfound_preview region (flora, editable, every knob at its default:
  chunk cull, occlusion, mdi + compact, shadow cull, dir cull, face pool, tjunction 2; LOD selection off),
  today's world hidden ({"hide_world":true,"show_preview":true}). One engine session, Release, 1600 x 900.
- Timing: perf_harness.py, 8 interleaved pairs x 240 GPU frames x 5 poses (f29_poses.json), pose read-back, engine
  defaults (wind, GI on) as F2.8. Only on a free GPU (WoW closed; the Battle.net launcher noted).
- GPU memory + bytes per frame: A = today's chunk quads x 16 B + card instances x 8 B; B = the face-pool image +
  sprigs x 8 B + tables; per frame = records drawn per pass (stats per pose) x record size.
- Pixels (new in this run; F2.8 measured none): §4.3's gate = per-pixel diff against today's render at the same poses,
  debug tonemap ({"curve":0}, LightingPipeline trap 1), wind 0, GI off (per-frame probe noise), 3D viewport only.
  Reported: % px differing > 8/255 (any channel), a control (A vs A again: 0 px expected), and a coverage split from
  debug view 11 (flat grey per voxel.frag fragment): px where one store shows sky and the other a surface (geometry)
  vs px where both show a surface (shading/material). The plan gives no numeric pixel threshold; this run records the
  numbers and their causes; it does not invent a pass mark after the fact.

template (missing on B); today's trees are 1/9 m templates, B's 1/8 m; B draws 225,471 sprigs vs today's 421,848
card instances (389,092 distinct).
