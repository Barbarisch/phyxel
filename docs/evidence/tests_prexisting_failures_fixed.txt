SURFACED — 3 (NOT changed; these are product/design decisions, not clear bugs):
  NavGridTest.StepUpOneBlock          MAX_STEP_UP = 0 is INTENTIONAL, documented at NavGrid.h:52-53:
  AStarPathfinderTest.PathUpOneBlockStep  "Set to 0 because there is no climbing mechanic — NPCs route
      around raised surfaces rather than stepping onto them. Increase if stair traversal is added." So
      the tests are STALE (they assert 1-block step-up, a deliberately-removed capability). "Fixing"
      them means either reverting the no-climb design (MAX_STEP_UP=1, global nav change) OR inverting
      the tests to assert no-climb. That is a design call — not made here.

      material. Reject-vs-overwrite is a placement-semantics design decision with engine-wide caller
      impact (some callers may rely on false-on-occupied). Not changed unilaterally.
