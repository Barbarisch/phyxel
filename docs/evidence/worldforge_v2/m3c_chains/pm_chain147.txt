READ FROM THE CODE (not measured): the forge's ground threshold = origin y * 9 + crawl * 9 + thicknessMicro(style
floor thickness) (StructureRealizer.cpp:172/196, StructureForge.cpp:837); the origin stands one cube above the pad, so
threshold - pad * 9 = 9 + floor micro for a slab: 12 for a 0.333 floor (timber_cottage, stone_manor), 14 for 0.5
(stone_keep, lround(4.5) = 5). The realizer does not compute this: it MEASURES it from earlier buildings of the same
style in the same build (sharedPadOffset) and uses 12 until one is measured.
