F2.15b prediction (written 2026-11-14 before any code): §4.6 item 8 continued, shadow casters by the light's direction.

Design: the preview's per-cluster shadow multidraw (F2.12's `shadow_mdi`, off by default because it measured slower)
uploads the per-DIRECTION clusters (F2.15) and the cull pass gets a light test: for a directional light every face of
one direction faces it or not at once, so a group casts only if dot(its normal, toLight) > -1e-4 (CPU reference
VoxFound::faceDirFacesLight). For a closed surface the nearest face along any light ray is a light-facing one, so the
shadow map's nearest depth is unchanged. Not exactly closed here: card (leaf) voxels emit no faces but hide their
neighbours' faces, so a ray entering a trunk through a hidden face could have hit a back face first. Runtime
{"shadow_dir_cull":bool} (needs shadow_mdi).

1. Unit (red first): random closed content (meshRuns, Outside::Air), random light directions, rays along the light:
   the nearest hit over the light-facing faces equals the nearest hit over all faces, for every ray. Red on a stub.
2. Pixels (main view, same pose, wind 0, GI off): shadow_mdi + dir test vs shadow_mdi alone: <= 0.05 % of the preview
   pixels (the card-adjacent gaps), controls 0. Casters drawn: 45-55 % of the faces.
3. Whole frame, A = the default (per-chunk caster draws), B = shadow_mdi + per-direction + light test: -1.0..-2.0 ms at
   every pose (preview casters cost ~4.5 ms at level 0 -- F2.13 -- half go; the multidraw's own overhead was
   +0.09..+0.36 ms with per-cell clusters and the commands are x4.6 now). B vs shadow_mdi alone (per-cell): -1.5..-2.5.
   If B wins at every pose: shadow_mdi + direction culling become the default.
