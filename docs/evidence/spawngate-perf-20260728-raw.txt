continuous solid above the spawn, and this world cannot host that: neither
/api/world/voxel nor /api/world/voxel/batch auto-creates chunks (a 24200-voxel column at
y40-240 returned placed:0 / failed:24200), so the tallest constructible column here is
the 14-cube one used above. The worst case is therefore bounded by ARITHMETIC, not
observation:
    old: <=1536 iterations x a full resolveSpawn (9 heights x up to 12 ring shells,
         ~5,000-11,000 AABB tests each)   ~= 8-17 MILLION AABB tests
    new: <=1536 iterations x 2 AABB tests ~= 3,072 AABB tests
i.e. ~3-4 orders of magnitude, with the iteration count itself unchanged and still hard-
capped at 512 m. Anyone who can build a >512 m column should re-run this and replace the
arithmetic with a number.
