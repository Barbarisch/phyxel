Design: a chunk's area is split into a SOLID grid (card voxels -> air) and a LEAF grid (only card voxels). Each gets
its own pyramid (lodBase/lodDown or LodBuilderGpu; the region pyramid for 2-16 m, each grid). Coarse level k (>= 1)
meshes the solid pyramid with neighbours from the solid pyramid only -- leaves no longer hide ground or trunk faces,
and a ground cell's surface vote sees the ground (its top touches air where the leaves were). Levels >= the handoff

faces). Level 0 unchanged (cards hide neighbours, today's mesher). Build {"lod_split_cards":bool}, default true; the
old meshing kept as an alternate level set so {"lod_cards_split":bool} swaps it at runtime (interleaved A/B).
