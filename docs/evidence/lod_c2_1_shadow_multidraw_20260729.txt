=== C2.1 — GPU-driven shadow submission: BLOCKED by an arena alignment contract ===

ROOT CAUSE: vkCmdDrawIndexedIndirect's firstInstance addresses instances by STRIDE, so a
chunk's arena span offset must be an exact multiple of sizeof(InstanceData)=24. Arena spans
are kAlignment=256-byte aligned (ChunkArenaAllocator.h:48) and 256 % 24 == 16, so offsets
are generally NOT stride multiples -> offset/24 TRUNCATES -> every chunk reads the wrong
instances. First A/B showed the symptom: shadow 3.3ms -> 11.6ms with wrong geometry.
A hard guard now refuses the path and falls back rather than render silent garbage.
