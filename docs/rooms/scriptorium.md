# scriptorium — Room Data Sheet

> Schema: [`README.md`](README.md). Used by: monastery, cathedral, the medieval alternative to a `printing_house`.

## Function
Copy + illuminate manuscripts by hand. **Strong light** is the defining requirement.

## Required fixtures (→ #17)
- **Desks / lecterns** (writing slopes).

## Typical fixtures (→ #16)
- Book/parchment storage (an armarium), ink + quills.

## Service
- **Strong window light** (to write/illuminate by); dry storage (parchment).

## Adjacency
- Off the **cloister** (often the north walk, the best light); near the library/armarium.

## Dimensions
- `to_ground`.

## Function testers
- **F1** Desks/lecterns to write at.
- **F2** **Strong natural light**.
- **F3** Dry book/parchment storage.

## Grounding ledger
- Desks + strong light — REUSE `monastery` / Part 3 scriptorium; size `to_ground`.
