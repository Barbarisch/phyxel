# bathing — Room Data Sheet

> Schema: [`README.md`](README.md). Used by: manor, bathhouse/stews (see the `bathhouse` archetype).

## Function
Wash/bathe. Service/private. (A dedicated bathing room is high-status or a public `bathhouse`.)

## Required fixtures (→ #17)
- A **tub** (or a vat).

## Typical fixtures (→ #16)
- A water source, a brazier/heat, a stool, hooks.

## Service
- **Water in + drainage out**; **heat** (a furnace/brazier).

## Adjacency
- Near a water source + the furnace; (stews) off a common room with let chambers (the brothel overlap).

## Dimensions
- `to_ground`; ceiling ≥ 2.134 m.

## Function testers
- **F1** A tub/vat.
- **F2** Water in + drainage out.
- **F3** A heat source.

## Grounding ledger
- Furnace-heated tubs (not a Roman hypocaust) — REUSE the `bathhouse` sheet (cited); size `to_ground`.
