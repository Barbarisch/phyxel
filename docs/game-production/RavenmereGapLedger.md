# Ravenmere — the "make a full short game" gap ledger

**Purpose.** Ravenmere (`PhyxelProjects/Ravenmere`, port 8104) is a deliberately complete
*short* Baldur's-Gate-like: story-driven, D&D turn-based combat, several distinct characters,
one engine-generated town, multiple quests, companions, a dungeon, save/load, a real ending.
It exists to find **what the engine + pipeline are missing** when you try to ship an actual game,
not to demo any one feature. Every hole we hit is a row here — with how it bit, the workaround
used (if any), and what the real fix is. Rows are dated; nothing is deleted, rows get a
**Status** update when fixed.

Companion docs: `StandaloneParityGaps.md` (the Hearthvale increments this builds on),
`README.md` (the production workflow), the project's own `GAMEPLAN.md`.

Severity: **S1** blocks the BG-like loop for a human player · **S2** forces an authoring
workaround that degrades the design · **S3** friction / polish.

## Design of the game (so the gaps have context)

- **Scenes:** `main_menu` → `town` (Ravenmere, engine-generated village) ⇄ `cellar` (tavern
  rats) · `town` ⇄ `farm` (Hollin Farm, wolves, the hermit's mill) ⇄ `barrow` (the Hollow
  Barrow: antechamber fight, crypt boss).
- **Cast:** Reeve Aldric (main quest giver), Priestess Maera (lore + alternate ending),
  Hobb (tavernkeeper, rats quest), Selby (merchant), Farmer Dunstan (wolves quest);
  companions **Bram** (fighter), **Wren** (rogue, in the stocks), **Oswin** (wizard hermit);
  villains the Hollow Priest + cultists + skeletons.
- **Quests:** main arc *The Missing* (6 objectives, branching ending: relic to the Reeve or
  broken on Maera's altar) + 4 side quests (rats, poacher, wolves, grimoire).
- **Player:** authored pre-made human cleric (see gap G-01).
