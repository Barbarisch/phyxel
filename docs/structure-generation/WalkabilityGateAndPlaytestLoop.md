## 2. Three layers, one agent

**One `AgentProfile`** (height, half-width, step-up, max fall, headroom) shared by the
TraversalProbe box, `NavAgentProfile`, and the player capsule — grounded in
`AnimatedVoxelCharacter` (`m_originalHalfWidth` = 0.25 m). A route the gate proves must be a
route the runtime can path and the player can walk; three oracles can only disagree.

**Layer A — generation-time gate (in the `build_settlement` job, on the REALIZED occupancy).**
Run after furnishing + item dressing, on the composed world (ChunkManager occupancy, not the plan):
- routes: street ↔ every exterior door ↔ every room centre ↔ every stair landing (upper floors);
  street connectivity between every pair of doors on the plan;
- door-threshold clearance: the 2-cube band inside and outside every door is free of furniture,
  props and fence;
- window walls are solid to the agent (G-57 teeth: the probe must NOT reach an interior through
  a shuttered window);
- lot permeability: every lot's rear/side space reachable from the street without crossing a
  building (G-59) — a lot-side gap ≥ 1.5 m or an alley per N lots, grounded before shipping.
Result: `walkability: {routes:[{label, walkable, pinchFrom, pinchTo, freeWidthMicro}], failed:N}`
in the job result and the settlement/worldforge ledger. A failing route is a **refusal or a
repair by the placer that caused it** (move the stool, re-cut the door), never a DB patch.

**Layer B — load-time self-check (shipped game).** On `onSceneReady`, path with `PathService`
from the spawn to every authored anchor: NPC positions, trigger regions, `locations`. Log a
`WorldHealth` report (`reachable N/M`, each failure with the anchor id + nearest pinch) and expose
it as `/api/rpg/world_health` so the harness asserts it before playing. Firing = a generator defect
escaped Layer A; the count is the metric.

**Layer C — playtest defect record.** One schema, one file per world
(`<project>/playtest/defects.jsonl`):
`{when, source: probe|player|selfcheck, world_seed, scene, pos, structure_id, lot, route_label,
invariant, evidence}`. Writers: the probe on `steer_stuck`/`no_path`; the self-check per failing
route; the player via a debug key ("report stuck here" — position + nearest structure id from
the placed-object registry). Readers: the fix loop below.

## 3. The loop

1. **Defect** lands in `defects.jsonl` (any source).
2. **Reproduce headless**: compose the same settlement (era/tier/seed are in the recipe) in the
   gate test and add the failing route as a **red** `SettlementWalkabilityTest` case. If the gate
   cannot see it (e.g. furniture), the gate's composition is the defect — widen it first.
3. **Fix the placer** (not the world). Green.
4. **Regenerate the world from the recipe** (`POST /api/settlement/build`, same seed — layout is
   deterministic, ~150 s for the 14-building town) and re-bake the scene DB. Hand-editing the DB
   is a provenance violation (CLAUDE.md hard rule).
5. **Re-run the probe** against the shipped build; the run is the L4 regression test; the
   self-check must report 0 failures.
