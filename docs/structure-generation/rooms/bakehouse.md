# bakehouse — Room Data Sheet

> Schema: [`README.md`](README.md). Used by: bakery, manor kitchen, monastery, inn. Reuses the `bakery` archetype sheet.

## Function
Bake bread around the **oven**. Fire-managed.

## Required fixtures (→ #17)
- A **masonry dome oven**.

## Typical fixtures (→ #16)
- A kneading table, a flour bin, a peel, a proving area.

## Service
- Oven **vented** (chimney #14); flour kept **dry**; **fire-safe** (often segregated/detached — fire law).

## Adjacency
- Oven on a **back/exterior wall**; the kneading table beside it; the flour store dry + near; the shop to the street.

## Dimensions
- Oven: a masonry dome, door **≈ 63 % of interior height** (cited, `bakery`); oven size `to_ground`.

## Function testers
- **F1** A masonry oven on a back/exterior wall, vented.
- **F2** A kneading table near the oven.
- **F3** Dry flour storage.
- **F4** Fire-safe (vented; segregated where a big oven).

- Dome oven + door ratio + fire-segregation — REUSE `bakery` (Masonry oven, cited); oven size `to_ground`.
